# 保存されたAIの判断を調べる操作確認

ご自身の能力を試すテストではありません。画面のわかりにくい点を見つけるための予備確認です。わからない、見つからない、続けたくない場合はそのまま伝えてください。設問のスキップ・休憩・中止で不利益はありません。

担当者から参加者コードと6個のリンクを受け取り、指定された順に1つずつ開いてください。Explorerと完全JSONの両方を使います。保存済みの同じ種類の情報が入っています。画面上のA/Bは比較する条件です。新たにAIを動かす必要はありません。

**共通ルール**

- 自分の回答と、根拠を見つけた場所を記録します。コピー＆ペーストしても構いません。
- ブラウザのページ内検索、折りたたみの展開、JSON保存、電卓を使えます。必要なものがあれば担当者に伝えてください。
- 課題中は指定された画面を使い、他方のUIや回答生成AIに切り替えないでください。
- 用語や操作の質問はできます。担当者からの支援があった場合は記録します。
- 確率は、提示された候補の間での相対的な確率です。答えが正しい確率とは限りません。

**各ケースで答えること**

1. **判断と確率**：AとBそれぞれの意味ラベル、型付き値、全候補の確率を教えてください。Noulの場合は`true`の確率も答えてください。
2. **Scoreの場合のみ**：A/Bの期待スコア、最も確率が高い段階、その差の絶対値、参照スコアを教えてください。参照スコアは丸めないでください。
3. **意味を揃えた比較**：各意味キーでB−Aの確率差を調べ、意味ラベルが変わったか答えてください。元の呼出しで使った候補トークンと意味キーの対応、表示順が記録されている場所も示してください。記録がない場合は「記録なし」で構いません。
4. **呼出しの数**：AとBそれぞれの物理呼出し数、両者が共有する数、重複を除いた合計数を答えてください。同じ物理呼出しを2回数えないでください。
5. **出典**：AとBを元データまでたどるためのZIP内ファイル名、1始まりの行番号、ファイルのSHA-256がある場所を教えてください。合成された条件では、元の物理呼出しの出典も探してください。ZIPを実際に開く追加作業は任意です。
6. **全体の分布**：A/Bの条件について、全200件で各ラベルが何回選ばれたか、最大のラベル占有率、選ばれたラベルの種類数を教えてください。Scoreでは期待値の最小・最大・分散も探してください。

最後に、各画面の難しさを1（とても簡単）〜7（とても難しい）で教えてください。便利だった点、迷った点、直してほしい点も自由にお知らせください。

この紙には正解は載っていません。回答の正しさは確認後に担当者が照合します。
