CChoice
The most likely candidate, returned as its semantic label.
NNoul
The probability assigned to the true candidate within a false/true pair.
SScore
The expected zero-based stage index, assuming equally spaced ordinal stages.

The released native system uses a frozen model with no trained decision head. The public API and browser expose candidate probabilities and typed values; raw candidate token IDs and logits remain in internal engine/research traces. Probabilities are normalized over the supplied candidates; concentration is not the probability of being correct.

Analysis outputs reproduced

CPU-only reanalysis reproduced the derived outputs byte for byte from retained records.

This is analysis replay. Native build and smoke checks used the same Mac and verified caches, not an independent replication.

A separate follow-up adds 4,800 measured calls: 240 Japanese JCommonsenseQA questions and 240 English CommonsenseQA questions, each evaluated by Qwen2.5-1.5B and Phi-4-mini. In the primary Phi-English comparison, entropy+order-TV and entropy alone have identical per-item correctness, 174/240 at 720 calls; fixed-random and first-entropy references score 180/240 and 177/240. Added order-TV benefit remains unestablished. All eight scores, both error targets, and four policies across five budgets are retained in the linked package.

A post-hoc control reuses those same 4,800 responses to compare arithmetic and normalized geometric averaging. Changing only the averaging rule changes 4–8 labels per 240-item stratum, without a consistent accuracy gain. Both rules share the same physical calls. All four strata and paired exploratory intervals are retained; this is no new inference or full AnyJev reproduction.

Scope, limitations, and prior work

The original three studies use Japanese public-data subsets; the latest separate follow-up covers Japanese and English five-choice tasks from two model families. All were run on one Apple Silicon Mac. The 480 follow-up questions are shared by two models, not 960 independent questions. Public-data contamination is unknown, and model family, size, language and dataset effects are not isolated. The separate 2,400-item local regression suite is AI-authored. No human observations or independent second-machine inference have been collected.

Probability averaging requires multiple model calls and does not consistently improve accuracy. The original model comparisons also differ in runtime and precision. Follow-up policy token and latency sums are saved-pool accounting, not measured online speedups.

LogitTrail, formerly Mini Jev, was inspired by TypeSafe's Jev. It does not reproduce Jev's architecture, training, calibration, speed, or protocol. The separate r-ms/mini-jev project is closely related prior work; LogitTrail is the UPHASH project formerly published under the same name. The paper situates candidate scoring and inspection alongside prior work including Ma et al., Hanna and Feng, LMQL, ChainForge, LLM Comparator, Langfuse, and Phoenix. The current revision also distinguishes LLM2Jev, AnyJev, and AudioJev; their full methods are not benchmarked here. Closely related scoring work includes Zhuang et al., Beyond Yes and No and Wang et al., Single-Token Expected-Value Scoring; LogitTrail does not claim to introduce candidate-logit normalization or expected-value scoring.
